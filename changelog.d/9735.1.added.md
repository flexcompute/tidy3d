`FieldStructureData` provides the loss current density `Jx_loss`/`Jy_loss`/`Jz_loss` on each component's native grid, the current in phase with the electric field (`sigma * E` in a conductive medium, so `0.5 * Re(J . E*)` is the absorbed power density), with `colocate_loss_current_density(...)` to place the components on common coordinates.
