Added `CanaliFieldDependence`, an extended Canali high-field velocity-saturation model that can be attached to `ConstantMobilityModel`, `CaugheyThomasMobility`, and `MasettiMobility` through their new `field_dependence` parameter (accelerated charge solver only). Velocity saturation must be specified for both carriers of a medium or for neither. Every mobility model now serializes `field_dependence`, so files written by this version do not load in older clients.
