Added `driving_force` and `reference_density` to `CanaliFieldDependence`. The default `driving_force="electric_field"` keeps the existing behavior. With `driving_force="quasi_fermi_gradient"` velocity saturation follows the gradient of the carrier quasi-Fermi potential, so the built-in fields of junctions and heterointerfaces do not reduce the mobility at equilibrium where the carrier density is well above `reference_density` (accelerated charge solver only). Each bias point is then solved twice, so the DC solve can take up to about twice as long. `CanaliFieldDependence` now serializes `driving_force`, so files written by this version do not load in older clients.
