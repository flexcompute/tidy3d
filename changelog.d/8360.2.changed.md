EME FlexCredit, run-time and memory estimates now account for cells whose permittivity tensor is not diagonal in the cell frame (a non-diagonal `FullyAnisotropicMedium`, or anisotropic media in bends with `bend_medium_frame="global"`): their separate backward mode solve, and the additional mode overlap and interface work and memory next to such cells. Storage estimates include the backward port modes when either port cell is such a cell, and the backward `n_complex` and `flux` of such cells in `EMECoefficientMonitor`s that record those fields. With frequency interpolation, these predictions use the frequencies actually solved, whether the stored fields are reduced or expanded.
