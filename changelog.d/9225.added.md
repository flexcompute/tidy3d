Added `Simulation.check_ports_reach_pml()` to find mode ports whose connected structures do not span the full absorbing layer, accounting for automatic structure extrusion and connected pieces in a `GeometryGroup` or union. The helper can be called in any validation mode. Set `config.validation.check_ports_reach_pml = True` to also enable pre-upload warnings for nearby ports in full validation mode; these warnings are disabled by default and skipped in fast mode.
